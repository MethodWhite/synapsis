# Synapsis + JetBrains IDEs

## Instalación

1. Abrir Settings → Tools → MCP Server
2. Agregar servidor:
   - Name: `synapsis`
   - Command: `/path/to/synapsis-mcp`
   - Args: (vacío)
3. Aplicar

O usar `synapsis-autoconfig --apply`.

## Uso

Los MCP tools de Synapsis estarán disponibles en cualquier IDE JetBrains
(IntelliJ IDEA, PyCharm, GoLand, WebStorm, Android Studio).

Requiere JetBrains AI Assistant habilitado.
